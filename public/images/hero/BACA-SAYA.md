# Folder Foto Hero

Letakkan foto hero utama di sini dengan nama file: `hero-alat-berat.jpg`

Rekomendasi:
- Resolusi minimal 1920x1080px
- Format JPG atau WEBP, dikompres agar ukuran file wajar (idealnya < 500KB)
- Foto alat berat (excavator/bulldozer) yang berkualitas tinggi dan tidak buram
- Jika menggunakan foto sementara (bukan dokumentasi unit asli), pastikan sumbernya legal
